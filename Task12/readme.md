Цель: Ознакомиться с паттерном MVVM (Model-View-ViewModel) в WPF, реализовав простое приложение «Список задач». 

Задача:Разработайте WPF-приложение для управления списком задач. Приложение должно включать три основных компонента:
  -	Model (Модель): Класс, представляющий задачу.
  -	ViewModel (Модель представления): Логика работы с задачами.
  -	View (Представление): Графический интерфейс пользователя.

Используемые библиотеки

1 Newtonsoft.Json: Библиотека для работы с JSON в C#. Используется для сериализации и десериализации объектов задач в формат JSON и обратно.

2 WPF: Используется для создания графического интерфейса пользователя. Позволяет создавать окна, кнопки, текстовые поля и другие элементы управления.

3 System.Collections.ObjectModel: Используется для работы с коллекциями, которые поддерживают уведомления об изменениях (например, `ObservableCollection`).

4 System.ComponentModel: Используется для реализации интерфейса `INotifyPropertyChanged`, который позволяет обновлять интерфейс при изменении данных.

Возникшие трудности:

1. Загрузка задач в ListBox: 
   - Сначала в `ListBox` при добавлении объектов `TaskItem` выводились сами объекты, а не их имена. Дело было в том, что метод `ToString()`, не был переопределен в классе `TaskItem`. Решение: добавление переопределения метода `ToString()`, чтобы выводить непосредственно имя задачи. 
2. Фильтрация задач: 
   - Сложности с обновлением списка задач после применения фильтра. Использование `ObservableCollection`, а также правильное уведомление об изменениях через `INotifyPropertyChanged` помогли это решить.
