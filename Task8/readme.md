Цель: создание WPF-приложения на C#, которое включает в себя элементы управления, такие как кнопки, текстовые поля, комбобоксы, слайдер и другие. Приложение должно было позволять пользователю взаимодействовать с элементами управления, изменять цвет фона окна, перемещать графические элементы (в данном случае, эллипс) и отображать информацию в текстовом поле в зависимости от действий пользователя.

Библиотеки:
System.Windows: для работы с основными элементами WPF, такими как окна, элементы управления и события.
System.Windows.Controls: для работы с элементами управления (кнопки, текстовые поля, комбобоксы).
System.Windows.Input: для обработки событий ввода.
System.Windows.Media: для работы с цветами и графическими элементами.

Трудности: 
Для начала возникли проблемы с правильным обработчиком для событий, таких как SelectionChanged для комбобокса и MouseMove для перемещения эллипса. Следовало строго следить за тем, какие события происходят и как они влияют на состояние элементов управления. Перемещение графических элементов: Реализация возможности перетаскивания эллипса на Canvas потребовала понимания, как работают координаты и события мыши. Неоднократные попытки были потрачены на то, чтобы прикосновение мыши произошло успешно и позиция эллипса была обновлена правильно.
Изменение фона: Проблемы появились при изменении цвет фона после изменения выбранного элемента в комбобоксе. Долго не удавалось преобразовать строковое значение в цвет. Пришлось воспользоваться BrushConverter, но ушло некоторое время, чтобы понять, как им пользоваться правильно.
Работа с ProgressBar: Настройка ProgressBar для индикации выполнения при работе с CheckBox.
