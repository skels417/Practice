Цель задания: Разработать приложение на языке C#, использующее WPF (Windows Presentation Foundation) для создания графического интерфейса. Приложение должно включать два окна: первое окно для ввода имени пользователя и верификации его корректности, а второе окно для отображения приветствия и информации о погоде. Также необходимо было реализовать функционал сохранения истории введенных имен в формате XML и отображения этой истории в виде таблицы.

Используемые библиотеки:
WPF - для создания графического интерфейса.
Newtonsoft.Json - для работы с JSON, используемым для получения данных о погоде через API.
System.Xml.Serialization - для сериализации объектов в XML формат.
System.Net.Http - для выполнения HTTP-запросов к API погоды.

Возникшие трудности
Работа с API: Первоначально возникли трудности с получением данных о погоде из API OpenWeatherMap. Необходимо было правильно настроить запрос и обработать полученные данные.
Сериализация в XML: При сохранении истории в XML возникли вопросы о том, как правильно сериализовать список объектов. Потребовалось изучить, как работает XmlSerializer.
Обработка событий: Необходимо было правильно настроить обработчики событий для управления интерфейсом, что потребовало дополнительного времени на изучение событий в WPF.

Используемые ресурсы:
Документация Microsoft по WPF: WPF Documentation - для изучения основ WPF и работы с элементами управления.
Документация по Newtonsoft.Json: Newtonsoft.Json Documentation - для работы с JSON.
Документация по XmlSerializer: XmlSerializer Documentation - для понимания сериализации объектов в XML.
OpenWeatherMap API: OpenWeatherMap API Documentation - для изучения возможностей API и примеров использования.
