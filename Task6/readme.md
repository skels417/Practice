Задача : Выполнить несколько заданий, связанных с многопоточностью, синхронизацией данных, использованием Task и асинхронным программированием.

Используемые библиотеки
- System.Threading
- System.Threading.Tasks
- System.Net.Http
- System.Collections.Concurrent
- 
 Возникшие трудности
1. При выполнении задания с гонками потоков возникали неожиданные результаты из-за отсутствия синхронизации.
2. В заданиях с асинхронным программированием были проблемы с обработкой исключений, которые требовали дополнительного внимания.
3. Параллельное вычисление факториала показало значительное улучшение производительности, но потребовало понимания работы с ConcurrentDictionary.
