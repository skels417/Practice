Цель: Разработать пользовательский контрол для реализации индикации. Контрол должен взаимодействовать с коллекцией изображений и в зависимости от параметра Value (int) выводить определенный элемент.

Библиотеки, применяемые в задаче: WPF (Windows Presentation Foundation): это главная библиотека для создания графического интерфейса в программах 
Windows. System.Windows.Controls: это библиотека для управления контролами вроде User Control, Image, Button и другими. 
System.Windows.Media.Imaging: это библиотека для работы с изображениями, в том числе для загрузки и подготовки изображений в формате PNG.
System.Windows.Threading: это библиотека для работы с таймерами и асинхронными операциями.

Шаги выполнения задачи:
1. Добавить новый User Control с именем ImageIndicator.xaml.
2. Добавить XAML структуру для отображения изображения. Реализовать логику контрола: 1. В ImageIndicator.xaml.cs добавить логику для управления изображениями, включая методы добавления и обновления изображений в соответствии с Value.
3. Реализовать таймер для анимированного обновления изображения. Создать основное окно.
4.  Внутри MainWindow.xaml добавить контрол и элементы управления (кнопки, текст боксы) для манипуляций с контролом.
5.   В MainWindow.xaml.cs добавить логику для перехвата событий кнопок и управления анимацией.
6.    Добавить изображения: экспортировать изображения из Draw.io c углом поворота 0, 120 и 240 градусов и сохранить в папку Images проекта. 2. Проверить пути к изображениям в коде.
